# Object-Oriented Programming (OOP) Programs

This folder contains beginner-friendly Python programs that demonstrate the core concepts of **Object-Oriented Programming (OOP)**. These exercises are designed to help understand classes, objects, inheritance, encapsulation, polymorphism, class variables, static methods, properties, and multiple inheritance in Python.

## Programs

### 1. Basic Class and Object
Create a `Car` class with attributes such as **brand** and **model**. Then create an instance of this class.

---

### 2. Class Method and `self`
Add a method to the `Car` class that displays the full name of the car by combining its **brand** and **model**.

---

### 3. Inheritance
Create an `ElectricCar` class that inherits from the `Car` class and includes an additional attribute.

---

### 4. Encapsulation
Modify the `Car` class to make the **brand** attribute private and provide a getter method to access it.

---

### 5. Polymorphism
Demonstrate polymorphism by defining a `fuel_type()` method in both the `Car` and `ElectricCar` classes, each returning a different value.

---

### 6. Class Variables
Add a class variable to the `Car` class that keeps track of the total number of car objects created.

---

### 7. Static Method
Add a static method to the `Car` class that returns a general description of a car.

---

### 8. Property Decorators
Use a property decorator in the `Car` class to make the **model** attribute read-only.

---

### 9. Class Inheritance and `isinstance()`
Demonstrate the use of the `isinstance()` function to check whether `my_tesla` is an instance of both the `Car` and `ElectricCar` classes.

---

### 10. Multiple Inheritance
Create two classes, `Battery` and `Engine`, and let the `ElectricCar` class inherit from both to demonstrate multiple inheritance.

---

These programs are intended to strengthen the understanding of **Object-Oriented Programming (OOP)** concepts through simple, real-world examples.
